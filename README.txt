# Expense Share Help Center

A responsive help/documentation website for the Expense Share Android app.

## Files

- index.html — complete website
- style.css — premium responsive styling
- script.js — mobile menu and help search
- assets/ — place your real app screenshots here

## Replace the placeholders with app screenshots

The current version intentionally uses "APP SCREEN / Replace with screenshot" placeholders because the actual app screenshots have not been provided yet.

When screenshots are available, replace the placeholder blocks in `index.html` with image elements, for example:

<img src="assets/home.png" alt="Expense Share Home screen">

You can also use the same screenshots in the detailed guide sections.
