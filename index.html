GUIDE 01

Login

Sign in to continue managing shared expenses.

  1. Enter your Email.
  2. Enter your Password. Use Show if needed.
  3. Tap LOG IN.
  4. Use Forgot Password? if required.
GUIDE 02

Home & Groups

Create, join and open your groups.

  1. Tap Create Group to start a group.
  2. Tap Join Group when you have an invite code.
  3. Use Search groups to find a group.
  4. Tap a group under My Groups to open it.
GUIDE 03

Create a Group

Set the group name, type and members.

  1. Enter the Group Name.
  2. Choose Trip, Room/flat or Personal.
  3. Add member names with the add button.
  4. Edit or delete members when needed.
  5. Tap Create.
GUIDE 04

Join a Group

Join using an invite code or scanner.

  1. Enter the Invite Code.
  2. Use Scan Code when available.
  3. Tap FIND GROUP.
  4. Confirm the group to start sharing.
GUIDE 05

Add an Expense

Record a payment and split it between members.

  1. Enter the Amount.
  2. Enter What was this for?
  3. Select Paid By.
  4. Check the Date.
  5. Choose members under Split between.
  6. Use Select all when everyone shares.
  7. Slide to Add Expense.
GUIDE 06

Expense Logs

Review recent expenses.

  1. Open Logs.
  2. Search by title or person.
  3. Use All, Pending or Synced.
  4. Review amount, payer and date.
  5. Edit or delete when permitted.
GUIDE 07

Settlement

See balances and who pays whom.

  1. Open Settle.
  2. Check Total Paid by Member.
  3. Review Who Pays Whom.
  4. Check the amount in each payment row.
  5. Tap Mark as Paid when available.
GUIDE 08

Profile & Settings

Manage settings, Help, feedback and account options.

  1. Open Profile from your avatar.
  2. Tap Settings for app preferences.
  3. Tap Help for this guide.
  4. Use Feedback to send suggestions.
  5. Use Privacy Policy, Share App and other options as needed.
